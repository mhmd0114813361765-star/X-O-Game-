
# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe (X-O) game** built using Java and JavaFX.

This project is a two-player game where players take turns placing X and O on a 3×3 board. The first player to get three matching symbols in a row, column, or diagonal wins!

## ✨ Features

- Interactive 3×3 game board.
- Two-player mode (X and O).
- Automatic turn switching.
- Win detection for rows, columns, and diagonals.
- Prevents players from selecting an occupied cell.
- Disables the board when a player wins.
- Restart button to start a new game.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- **Java** – Programming language.
- **JavaFX** – Graphical User Interface (GUI).
- **Maven** – Project management and dependencies.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Java Development Kit (JDK).
- Apache Maven.
- Visual Studio Code or another Java IDE.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/mhmd0114813361765-star/TIC-TAC-TOE-Game.git
```

2. Open the project folder:

```bash
cd TIC-TAC-TOE-Game/demo
```

3. Run the application using Maven (if the JavaFX Maven plugin is configured):

```bash
mvn clean javafx:run
```

## 🎯 How to Play

1. Launch the game.
2. Player X starts first.
3. Player O plays after X.
4. Players take turns selecting empty cells.
5. The first player to connect three matching symbols wins.
6. Click **Restart** to play again.
